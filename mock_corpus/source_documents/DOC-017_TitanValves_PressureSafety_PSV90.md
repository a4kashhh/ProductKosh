# Technical Manual: Titan PSV90 Spring-Loaded Pressure Safety Relief Valve
**Manufacturer**: Titan Valves & Controls
**Series**: PSV90 Safety Series
**UNSPSC Taxonomy**: 40141604 (Safety relief valves)

## Technical Specifications
- **Inlet Size**: 1 inch to 8 inch (DN25 - DN200) Flanged ANSI 150# to 2500#
- **Set Pressure Range**: 1.5 Bar to 250 Bar (21.7 PSI to 3625 PSI)
- **Orifice Letter Designation**: Orifice D through Orifice T per API 526
- **Operating Temperature Range**: -45°C to 538°C (-49°F to 1000°F)
- **Overpressure**: 10% for Steam and Gas, 21% for Fire Case
- **Body Material**: Cast Carbon Steel WCB / Chrome-Moly Alloy Steel WC6 / CF8M SS
- **Trim Material**: 316 Stainless Steel with Stellite Faced Disc

## Compliance & Standards
- **ASME Code**: ASME Boiler & Pressure Vessel Code Section VIII Division 1 (UV Stamp)
- **Design Standard**: API 526 / API 520 Sizing
- **Testing Standard**: API 527 Seat Tightness
- **Pressure Equipment Directive**: CE / PED 2014/68/EU Category IV

## Applications
Overpressure protection on steam boilers, gas oil separators, chemical pressure vessels.
