# Technical Datasheet: L&T Valves Severe Service Ball Valve
**Manufacturer**: L&T Valves Limited (Larsen & Toubro)
**Product Line**: V200 Severe Service Series
**UNSPSC Taxonomy**: 40141607 (Ball valves)
**Make in India**: Class 1 Local Supplier (Make in India Compliant)

## Technical Specifications
- **Valve Size**: 2 inch to 12 inch (DN50 - DN300)
- **Pressure Class**: ANSI Class 150, 300, 600, 900, 1500 (PN 20 to PN 250)
- **Max Operating Pressure**: 258 Bar (3750 PSI / 263 kg/cm²)
- **Operating Temperature Range**: -29°C to 538°C
- **Body Material**: Cast Carbon Steel IS 210 / ASTM A216 WCB / Stainless Steel IS 3444 / A351 CF8M
- **Ball & Stem Material**: 17-4PH Stainless Steel with Colmonoy Hardcoating
- **Seat Type**: Metal-Seated with Stellite 6 Hardfacing
- **End Connections**: Flanged RF per ASME B16.5, Butt Weld (BW)
- **Seat Leakage Rate**: ISO 5208 Rate A / ANSI/FCI 70-2 Class VI (Zero Leakage)
- **Flow Coefficient (Cv)**: 210 for 2-inch, 3800 for 12-inch

## Compliance & Standards
- **Indian Standard**: BIS IS 778 / IS 14846 / IBR (Indian Boiler Regulations) 1950
- **Statutory Approvals**: PESO Approved (Petroleum and Explosives Safety Organization)
- **Design Standard**: API 6D / ASME B16.34
- **Fire Safety**: API 607 7th Edition / ISO 10497
- **Fugitive Emissions**: ISO 15848-1 Class AH
- **Quality System**: ISO 9001:2015 / BIS Mark Certified

## Typical Indian Industrial Applications
NTPC power plant steam isolation, IOCL/BPCL refinery catalytic cracking, ONGC offshore skids, and fertilizer blowdown.
