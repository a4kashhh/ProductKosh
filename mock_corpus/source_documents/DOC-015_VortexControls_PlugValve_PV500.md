# Technical Datasheet: Vortex PV500 PTFE-Sleeved Non-Lubricated Plug Valve
**Manufacturer**: Vortex Controls Inc.
**Series**: PV500 Sleeve-Sealed Series
**UNSPSC Taxonomy**: 40141600 (Industrial Valves - Plug Valves)

## Technical Specifications
- **Valve Size**: 1/2 inch to 10 inch (DN15 - DN250)
- **Pressure Class**: ANSI Class 150, 300
- **Max Operating Pressure**: 740 PSI (51 Bar)
- **Operating Temperature**: -29°C to 204°C (-20°F to 400°F)
- **Body Material**: Ductile Iron / Carbon Steel A216 WCB / Monel 400 / Alloy 20
- **Plug Material**: 316 Stainless Steel / Hastelloy C
- **Sleeve Material**: Virgin PTFE / Fluorosinter High Temp PTFE
- **Port Option**: Standard Port / Full Port / 3-Way Multiport

## Compliance & Standards
- **Design Standard**: API 599 / ASME B16.34
- **Testing Standard**: API 598 Zero Bubble Leakage
- **Fugitive Emissions**: TA-Luft / ISO 15848-1 Class AH
- **Fire Safety**: API 607 5th Edition

## Applications
Corrosive chemical services, hydrofluoric acid handling, chlorine manufacturing.
