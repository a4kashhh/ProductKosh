# Technical Datasheet: Flowserve V200 Severe Service Ball Valve
**Manufacturer**: Flowserve Flow Control
**Product Line**: V200 Severe Service Series
**UNSPSC Taxonomy**: 40141607 (Ball valves)

## Technical Specifications
- **Valve Size**: 2 inch to 12 inch (DN50 - DN300)
- **Pressure Class**: ANSI Class 150, 300, 600, 900, 1500 PSI
- **Max Operating Pressure**: 3750 PSI (258.5 Bar)
- **Operating Temperature Range**: -29°C to 538°C (-20°F to 1000°F)
- **Body Material**: ASTM A216 Grade WCB Carbon Steel / ASTM A351 Grade CF8M 316 Stainless Steel
- **Ball & Stem Material**: 17-4PH Stainless Steel with Colmonoy Hardcoating
- **Seat Type**: Metal-Seated with Stellite Hardfacing
- **End Connections**: Flanged RF (Raised Face), Butt Weld (BW)
- **Seat Leakage Rate**: ISO 5208 Rate A / ANSI/FCI 70-2 Class VI (Zero Leakage)
- **Flow Coefficient (Cv)**: 210 for 2-inch, 3800 for 12-inch

## Compliance & Standards
- **Design Standard**: API 6D / ASME B16.34
- **Fire Safety**: API 607 7th Edition / ISO 10497
- **Fugitive Emissions**: ISO 15848-1 Class AH / EPA Method 21
- **Quality System**: ISO 9001:2015 Certified
- **Functional Safety**: SIL 3 Capable per IEC 61508
- **Pressure Equipment**: CE / PED 2014/68/EU Compliant

## Typical Applications
High-pressure steam isolation, refinery catalytic cracking, severe slurry service, and power plant blowdown.
