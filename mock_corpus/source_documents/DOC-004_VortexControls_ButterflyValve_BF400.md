# Technical Manual: Vortex BF400 Triple-Offset Butterfly Valve
**Manufacturer**: Vortex Controls Inc.
**Product Series**: BF400 High Performance
**UNSPSC Taxonomy**: 40141615 (Butterfly valves)

## Technical Specifications
- **Valve Size Range**: 3 inch to 24 inch (DN80 - DN600)
- **Pressure Class Rating**: ANSI Class 150, 300, 600
- **Max Operating Pressure**: 1480 PSI (102 Bar)
- **Temperature Rating**: -196°C Cryogenic to +450°C High Temp (-320°F to 842°F)
- **Body & Disc Material**: ASTM A351 CF8M Stainless Steel / Hastelloy C
- **Shaft Material**: 17-4PH / Inconel 718 High Strength Alloy
- **Seat Ring**: Laminated SS316 with Graphite / Stellite 6 Solid Seat
- **Flow Characteristic**: Modified Equal Percentage
- **Tightness Class**: ISO 5208 Rate A / ANSI FCI 70-2 Class VI Zero Leakage Bi-Directional

## Compliance & Standards
- **Design Standard**: API 609 Category B / ASME B16.34
- **Fire Safe Standard**: API 607 6th Edition / ISO 10497
- **Fugitive Emissions**: ISO 15848-1 Class BH
- **Pressure Equipment**: CE / PED 2014/68/EU Module H

## Applications
LNG liquefaction facilities, high-temperature exhaust gas isolation, district heating networks.
