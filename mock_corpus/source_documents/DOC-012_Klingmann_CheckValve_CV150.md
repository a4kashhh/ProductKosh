# Engineering Datasheet: Klingmann CV150 Dual-Plate Wafer Check Valve
**Manufacturer**: Klingmann Valve Works
**Series**: CV150 Dual Plate
**UNSPSC Taxonomy**: 40141601 (Check valves)

## Technical Specifications
- **Size Range**: 2 inch to 16 inch (DN50 - DN400)
- **Pressure Class**: ANSI Class 150, 300
- **Max Operating Pressure**: 740 PSI (51 Bar)
- **Temperature Limits**: -29°C to 230°C (-20°F to 446°F)
- **Cracking Pressure**: 0.15 PSI (0.01 Bar) Low Cracking Pressure
- **Body Material**: Ductile Iron A536 / Cast Carbon Steel A216 WCB / SS316
- **Plate / Disc Material**: ASTM A351 CF8M Stainless Steel
- **Spring Material**: Inconel X-750 High Strength Alloy
- **Seat Seal**: EPDM / Viton / Metal-to-Metal

## Compliance & Standards
- **Design Standard**: API 594 / ASME B16.34
- **Testing Standard**: API 598 Pressure Testing
- **Face-to-Face Dimension**: API 594 Wafer Pattern
- **Quality Assurance**: ISO 9001:2015

## Applications
Preventing backflow in pump discharge lines, HVAC chilled water loops, seawater cooling lines.
