# Product Spec: ValvTech GV900 Forged Steel Gate Valve
**Manufacturer**: ValvTech Engineering
**Series**: GV900 Forged Series
**UNSPSC Taxonomy**: 40141603 (Gate valves)

## Technical Specifications
- **Valve Size**: 1/2 inch to 2 inch (DN15 - DN50)
- **Pressure Class**: ANSI Class 800, Class 1500
- **Max Operating Pressure**: 3705 PSI (255 Bar)
- **Operating Temperature Range**: -29°C to 450°C (-20°F to 842°F)
- **Body & Bonnet Material**: ASTM A105 Forged Carbon Steel / ASTM A182 F316 SS
- **Wedge & Stem**: Solid Wedge 13% Cr Stainless Steel / Stellite 6 Trim 8
- **End Connections**: Threaded NPT / Socket Weld (SW)
- **Packing**: Die-formed Flexible Graphite with Anti-Corrosion Inhibitor

## Compliance & Standards
- **Design Standard**: API 602 / BS 5352 / ASME B16.34
- **Testing Standard**: API 598 Pressure Inspection
- **Fugitive Emissions**: ISO 15848-1 Class BH
- **Quality System**: ISO 9001:2015

## Applications
High-pressure drain and vent lines, refinery hydrocarbon sampling lines, boiler trim.
